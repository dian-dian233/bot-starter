# bot-starter

给「想要一个自己的群聊 bot」的人用的最小骨架。不是框架，是三样东西的落地写法：**人格 / 记忆 / 执行**。

## 三样东西

| 目录 | 是什么 | 换成你自己的 |
| --- | --- | --- |
| `persona.md` | 人格设定，粘进 AstrBot/框架的 system prompt | 改名字、改语气、改禁区 |
| `memory/` | 事实型记忆库（sqlite，三元组 + 覆盖 + 时间） | 不用改，直接用 |
| `bootstrap.sh` | 新环境一条命令复原：登录态、记忆、技能 | 改仓库地址和代理即可 |

## 为什么这样分

- **人格**决定它像谁；**记忆**决定它记得事；**执行**决定它能干活。这三样定了，框架随便换。
- 记忆不放在框架里，放 Git。框架换了、机器换了、会话清了，记忆还在。
- 重活不在聊天进程里跑，丢给一台能 SSH 的机器；聊天进程只负责收发消息。

## 三步上手

1. 把 `persona.md` 的内容贴进你框架的人格配置
2. `python3 memory/mem.py init`，然后每天 `add` / `search`
3. 新环境跑 `bash bootstrap.sh` 把记忆和凭证拉回来

## 一条硬规则

> 涉及「上次/之前/我让你记的」→ 先 `mem.py search`，再回答；查不到就说没记录。

这条比任何框架选择都重要。
